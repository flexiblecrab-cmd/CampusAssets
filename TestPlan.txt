4. Optional extra checks (add to `Program.cs`)

Paste these into `Program.cs` inside the `try` block, then run `dotnet run`. Each line must print `Rejected as expected`.

After the existing "Delete a borrower who has loans" check (the loan is still active here):

```csharp
await ExpectErrorAsync("Duplicate email",
    () => service.AddBorrowerAsync("Other Person", $"maria.{tag}@campus.edu"));
await ExpectErrorAsync("Duplicate asset tag",
    () => service.AddEquipmentAsync($"LAP-{tag}", "Another Laptop"));
await ExpectErrorAsync("Delete equipment that has loans",
    () => service.DeleteEquipmentAsync(equipmentId));
await ExpectErrorAsync("Delete an active loan",
    () => service.DeleteLoanAsync(loanId));
await ExpectErrorAsync("Check out for an unknown borrower",
    () => service.CheckOutAsync(99999, equipmentId));
await ExpectErrorAsync("Search with 'from' after 'to'",
    () => service.SearchLoansAsync(borrowedFrom: DateTime.UtcNow, borrowedTo: DateTime.UtcNow.AddDays(-2)));
```

Right after `await service.ReturnLoanAsync(loanId);`:

```csharp
await ExpectErrorAsync("Return the same loan twice",
```
